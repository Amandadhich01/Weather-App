# 🌤️ Weather Forecast Application

A responsive, real-time weather forecasting web application built with **React**, **Vite**, **Material UI (MUI)**, and the **OpenWeatherMap REST API**.

## 🚀 Live Demo
- **Live Application:** [https://amandadhich01.github.io/Weather-App/](https://amandadhich01.github.io/Weather-App/)
- **Author:** [Aman Dadhich](https://github.com/Amandadhich01)

## ✨ Features
- **Real-Time Weather Metrics:** Fetches live temperature, feels-like temperature, humidity, min/max bounds, and sky conditions for any city worldwide.
- **Dynamic UI & Visual Feedback:** Adapts cards, imagery, and weather icons (Hot, Cold, Rainy) automatically based on temperature and atmospheric metrics.
- **Material UI Design:** Built with clean, responsive cards, input controls, and elevation styling using `@mui/material` and `@mui/icons-material`.
- **Error Handling & Validation:** Graceful error reporting for invalid city queries without breaking application state.

## 🛠️ Tech Stack
- **Frontend:** React 19, JavaScript (ES6+), HTML5, CSS3
- **Component Library:** Material UI (MUI)
- **Tooling & Bundler:** Vite
- **API:** OpenWeatherMap Weather API

## 💻 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Amandadhich01/Weather-App.git
   cd Weather-App
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
